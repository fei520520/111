# 研究方向：面向视障用户的主动澄清式视觉对话

> 本文件是这条研究线的**主文档**：问题定义、假设、指标、数据协议与进度都记录在这里。
> 与 `layered-place-memory.md`（空间记忆线）**正交**：那条线研究"跨时间记住地点"，本条研究"当下把一句话说清楚"。

## 1. 问题（为什么需要澄清）

现有第一视角视觉助理（含 FirstSight 的 RequestAgent、Seeing AI 等）都是**单轮流水线**：
用户提问/拍照 → VLM 回答。真实交互中证据经常不足：

- 画面模糊、遮挡、视野没对准目标；
- 用户说"帮我拿那个"，指代不明；
- 目标根本不在当前画面里。

人类协助者会自然澄清（"你说的是左边那个吗？""能靠近点吗？"），而 AI 往往**硬猜**。对视障用户而言，
**答错比多问一句代价高得多**，所以正确动作不是猜，而是**澄清**。

## 2. 研究问题与假设（可证伪）

- **H1（能否知道该问）**：当视觉证据不足时，系统能否可靠地识别"该澄清"，而不是硬猜或乱问？
- **H2（问什么最省事）**：在"口头提问"与"请求改变视角"之间，何种澄清动作信息增益/打扰比最高？
- **H3（对用户的价值）**：主动澄清能否提升视障用户的任务成功率与信任，且不显著增加认知负荷？

## 3. 形式化

建模为**带人类在环的 POMDP**：

| 元素 | 含义 |
|---|---|
| 状态 `s` | 场景真实内容 + 用户真实意图 |
| 观测 `o` | 当前图像（及语音输入） |
| 动作 `a` | `answer` / `ask_verbal`（口头澄清）/ `ask_view`（请求改变视角）/ `abstain` |
| 转移 | `ask_view` → 用户移动手机 → 新图像（观测偏移由人产生） |
| 奖励 | `任务成功 − α·错误代价 − β·打扰次数 − γ·延迟` |

关键不同：澄清由**人来执行**（人 = 传感器 + 执行器），且在**无位姿、单目**约束下。

## 4. 与现有工作的区别（Gap）

| 领域 | 代表 | 与本方向的差异 |
|---|---|---|
| Visual Dialogue | VisDial | 多轮但**无任务、无澄清决策** |
| Clarification questions (NLP) | —— | 几乎只处理**文本歧义**，不含视觉/视角 |
| Active perception / NBV | 机器人 | 是**自主移动**，不是"请人转头" |
| Assistive 视觉 | Seeing AI 等 | 多为单轮描述/问答 |

本方向的空白：**以人为传感器的、面向无障碍的澄清式视觉对话**。

## 5. 指标定义

| 指标 | 定义 | 为什么重要 |
|---|---|---|
| 任务成功率 | 澄清结束后答对的比例 | 主指标 |
| **信息增益** | 澄清前后"答案分布"的变化量，**不靠主观标注** | 让"该不该问"可量化 |
| 澄清次数 | 每个任务平均澄清动作数 | 打扰度量 |
| 打扰率 | 每分钟打断次数 | 用户体验 |
| 校准 | ECE / risk-coverage 曲线 | 让"不确定"可信 |

> 信息增益的定义是本研究的**地基地**：用"澄清前 vs 澄清后模型给出正确答案的概率差"来度量，
> 从而把"该不该澄清"变成一个可计算的目标，而不是主观判断。

## 6. 数据集协议（v1）

每个样本一行 JSON（`manifest.jsonl`）：

```json
{
  "id": "amb-0001",
  "source_image": "run/experiments/<session>/live/frame-0001.jpg",
  "image": "images/amb-0001.jpg",
  "ambiguity": ["blur"],
  "params": { "sigma": 6 },
  "seed": 0
}
```

歧义类型（可叠加）：

| 类型 | 含义 | 注入方式 |
|---|---|---|
| `blur` | 运动/对焦模糊 | 高斯模糊 |
| `crop` | 视野不足（目标在画面外） | 随机裁切后放大 |
| `occlude` | 遮挡 | 叠加色块 |
| `dark` | 欠曝 | 降低亮度 |
| `downscale` | 低分辨率 | 缩小再放大 |

真值（意图 / 期望澄清动作）在**阶段 1 后期**由人工或规则补，避免一开始就依赖主观标注。

## 9. 进度记录

- 2026-10-12：建立本文件；确立问题、假设、指标与数据协议；进入阶段 1。
- 2026-10-12：实现 `sim/inject_ambiguity.py`（歧义注入 + 清晰度筛选）与 `sim/eval_clarify_baseline.py`（自报置信度评测）。
- **初步结果（n=2，仅示意，非结论）**：干净图置信度 0.935；`blur` 后骤降至 0.525（−0.41），
  而 `crop/dark/downscale/occlude` 仅降至 0.85–0.9（−0.03–0.09）。
  → 模型**只对模糊敏感**，对裁切/遮挡/变暗/降分辨率**过度自信**——正是主动澄清要解决的失效模式。
- **工程发现**：`run/experiments` 的手机帧质量参差（很多本身运动模糊），必须先用清晰度筛选才能当"干净底图"。
- **阶段 1 初步结果（n=40，每类 8；`run/research/ambiguous-v3/eval/`）**：

  | 歧义 | 歧义置信度 | 干净置信度 | 下降 | 答案相似度 | 过度自信率 |
  |---|---|---|---|---|---|
  | blur | 0.613 | 0.934 | 0.321 | 0.187 | 0.375 |
  | crop | 0.875 | 0.934 | 0.059 | 0.150 | **1.000** |
  | dark | 0.806 | 0.934 | 0.127 | 0.361 | 0.250 |
  | downscale | 0.819 | 0.934 | 0.115 | 0.294 | 0.250 |
  | occlude | 0.877 | 0.934 | 0.056 | 0.280 | **0.625** |

  - **发现 A**：`crop`/`occlude` 下模型几乎不降置信度，但答案与干净图严重不符 → 目标移出画面或被遮挡时**自信地描述错误内容**。
  - **发现 B（关键）**：风险-覆盖曲线反常（最高置信度 10% 子集错误率 0.75，全量 0.65，几乎不降）→ **自报置信度未校准，不能用于判断"该不该澄清"**。这为本研究提供了核心动机：需要**独立的、校准的不确定性估计**。
  - 限制：样本小（n=40）；"答案相似度"是字符 2-gram Jaccard 的粗代理，非人工判定；单一模型 `qwen3-vl-plus`；单一问题。结论为**开发者基线**，非验证性结论。
- **阶段 2（不确定性信号）初步结果**（`sim/analyze_uncertainty.py` → `run/research/ambiguous-v3/analysis.json`）：
  整体准确率仅 0.35（歧义下答案与干净图一致的比例）。各信号预测"答对"的 AUC：

  | 信号 | AUC（整体） |
  |---|---|
  | **sharpness（图像清晰度）** | **0.701** |
  | dark_ratio | 0.657 |
  | model_confidence（模型自报） | 0.626 |
  | contrast | 0.492 |
  | brightness | 0.396 |

  - **发现 C**：简单的图像清晰度特征（0.701）**比模型自报置信度（0.626）更能预测答错** → 佐证"不能依赖模型自省"。
  - **发现 D**：**crop（裁切）准确率 0%**，模型仍报 0.875 置信度 → 最严重、最该澄清的场景。
  - **发现 E（贡献点）**：**没有单一信号覆盖所有歧义**——blur 靠 contrast、dark 靠 sharpness、downscale 靠模型置信度，而 crop/occlude 下**所有信号失效**。因此必须**自适应组合信号 + 主动澄清**。
- **阶段 2 触发对比**（`analysis.json` → `triggerComparison`，按信号排序后看错误率随覆盖率的变化）：
  - **模型自报置信度**：最可信 10% 错误率 **0.75**，全量 0.65 → 几乎不降（最"自信"的反而错最多）。
  - **图像清晰度**：最可信 10% 错误率 **0.25**，随覆盖率升到 0.65 → 明显有效。
  - 等权融合（conf+sharp）AUC 0.684，**未超过**单用 sharpness（0.701）→ 融合需**学习权重**，非简单平均。
  - **结论**：模型自报置信度**不可用于触发澄清**；图像质量是更好的起点，但需自适应融合。
- **阶段 3–4 澄清策略模拟**（`sim/simulate_clarify_policy.py` → `policy.json`，假设"澄清后必定答对"的乐观上界，隔离触发策略本身）：
  不澄清时准确率仅 0.35；各策略达到目标准确率所需的**澄清比例**：

  | 触发信号 | →0.7 | →0.8 | →0.9 |
  |---|---|---|---|
  | 不澄清 | 达不到 | 达不到 | 达不到 |
  | 模型自报置信度 | 50% | 70% | 90% |
  | **图像清晰度** | 50% | **60%** | **80%** |
  | 融合 | 50% | 70% | 80% |

  - **发现 F**：图像清晰度作触发器一致优于模型自报置信度（高目标时省 ~10% 澄清）。
  - **发现 G（论证核心）**：**没有任何离线信号能把澄清成本大幅降低**（到 0.9 需澄清 80–90%）→ 仅"判断要不要问"不够，**必须真正换视角获取新证据**（`ask_view`），这正是主动感知的价值所在。
